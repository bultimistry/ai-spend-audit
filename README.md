# AI Spend Audit

AI Spend Audit helps teams analyze AI tooling costs, identify overspending, and discover optimization opportunities.

## Features

- AI tooling spend analysis
- Personalized audit recommendations
- Shareable audit reports
- AI-generated summaries
- Lead capture + email delivery
- Public shareable URLs
- Persistent form state
- Automated testing + CI

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Anthropic API
- Resend
- Zustand
- Vitest

## Local Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm test -- --run
```

## Deployment

Deployed on Vercel.
